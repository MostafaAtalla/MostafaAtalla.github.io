This is a sample essay that shows how posts render on the site. Replace this text with your own essay. Everything below is formatting you can reuse.

## Writing a post

Each essay is a plain Markdown file in the `posts/` folder. Its file name is the `slug` you list in `assets/js/data.js`, so this file, `the-art-of-science.md`, belongs to the entry with `slug: "the-art-of-science"`.

You can use **bold**, *italics*, [links](https://doi.org/10.1063/5.0149501), lists and images:

- Put images in `assets/photos/` and reference them as `![caption](assets/photos/my-figure.jpg)`
- Use `>` at the start of a line for a pull quote
- Use `##` for section headings

## Publishing

Commit the new file and the entry in `data.js`, push to GitHub, and the essay appears on the Writing page within a minute or two.
